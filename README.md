# Dibla Frontend - Gold Market Application

## Overview
Dibla is a platform for browsing and showcasing gold and jewelry stores in Egypt, with features for booking appointments and store reviews.

## Features
- User authentication and registration (Email/Password + Google OAuth)
- Two types of users: Customers and Store Owners
- Store management and browsing
- Product management (Necklaces, Rings, Bracelets)
- Appointment booking system
- Store rating system
- Favorites list
- Mobile responsive design

## Tech Stack
- **Frontend**: React 18 + Vite
- **Styling**: Tailwind CSS + shadcn/ui
- **Routing**: React Router DOM
- **State Management**: React Context API
- **HTTP Client**: Axios
- **Icons**: Lucide React
- **Animations**: Framer Motion
